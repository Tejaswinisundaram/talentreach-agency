# TalentReach – HR Staffing & Digital Marketing Agency Website

TalentReach is a responsive, frontend-only website concept that combines **HR staffing and recruitment services with digital marketing solutions**. Built using HTML, CSS, and JavaScript, the website showcases agency services, displays sample job opportunities, and allows users to search and filter jobs and express their interest through a contact form.

## 🎯 Project Overview

1. **Goal:** To create a professional, responsive website for an agency offering recruitment, staffing, and digital marketing services.
2. **Project Type:** Frontend web development.
3. **Tech Stack:** HTML5, CSS3, JavaScript.
4. **Development Environment:** Visual Studio Code, Microsoft Edge, and Live Server.
5. **Target Users:** Job seekers, businesses looking for recruitment support, and organizations interested in digital marketing services.

## 🔍 Features

1. **Responsive Navigation:** Provides easy navigation between the Home, Services, Careers, and Contact sections.
2. **Agency Services Showcase:** Highlights Talent Acquisition, Digital Campaigns, and Employer Branding services through structured content and cards.
3. **Featured Job Listings:** Displays sample opportunities for Frontend Developer, Digital Marketing Intern, and HR Recruiter roles.
4. **Job Search and Category Filtering:** Enables users to find relevant opportunities using keywords and filter listings by Technology, Marketing, and Human Resources.
5. **Interactive Apply Now Buttons:** Automatically populate the contact form with the selected job title and direct users to the application inquiry section.
6. **Contact Form with Validation:** Collects user details and validates required fields before displaying a confirmation message.
7. **Responsive and Accessible Design:** Adapts to desktop, tablet, and mobile screens while supporting keyboard navigation and visible focus indicators.

## 🚀 How to Run the Website Locally

### 1. Prerequisites

- Visual Studio Code.
- A modern web browser, such as Microsoft Edge or Google Chrome.
- The Live Server extension in Visual Studio Code (recommended).

### 2. Installation and Setup

1. Download or clone the project repository.
2. Open the `talentreach-agency` folder in Visual Studio Code.
3. Ensure all required files are present.
4. Install the Live Server extension if necessary.
5. Right-click `index.html` and select **Open with Live Server**.

### 3. Run the Website

The website will open in your default browser. Save any changes made to the HTML, CSS, or JavaScript files and refresh the page if necessary.

### 4. Required Files

- `index.html` — website structure and content.
- `style.css` — styling and responsive layouts.
- `script.js` — job search, filtering, and form interactions.
- `README.md` — project documentation.
