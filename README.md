
# TalentReach

A responsive frontend website concept combining
digital marketing and HR staffing services.

## Project Overview

TalentReach demonstrates how a fictional agency can
present recruitment, staffing, employer branding,
and digital marketing services on one website.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid and media queries

## Features

- Responsive homepage and navigation
- Staffing and digital marketing service sections
- Sample job listings
- Job search and category filtering
- Apply Now buttons that prefill the contact form
- Basic client-side form validation
- Responsive contact form and visual feedback

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.

## Current Limitations

- Job listings are sample data.
- Applications are not saved to a database.
- Contact messages are not sent to an agency.
- There is no login system or admin dashboard.

## Future Improvements

- Connect a backend and database.
- Add real job and candidate management.
- Create an employer dashboard.
- Integrate a working contact and application service.
